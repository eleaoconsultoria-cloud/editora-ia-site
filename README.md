# Site Editora I.A.

Página institucional estática em português, com identidade visual baseada no logotipo oficial da Editora I.A.

## Arquivos

- `index.html` — conteúdo e estrutura semântica da página.
- `styles.css` — identidade visual e regras responsivas.
- `assets/logo-editora-ia.webp` — logotipo da Editora I.A.

## Publicação no GitHub Pages

O site não requer processo de compilação nem dependências. Publique o conteúdo desta pasta na raiz do repositório ou configure o GitHub Pages para usar esta pasta como origem.

Os estilos usam fontes disponíveis no dispositivo e não carregam bibliotecas ou fontes externas.
